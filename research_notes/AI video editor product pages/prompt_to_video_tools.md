# Prompt-to-video and avatar video platforms: product page structure (InVideo AI, Pictory, Synthesia, HeyGen)

Research date: 2026-11-04. All pages were read live through a page-to-text fetcher. That means visual layout, animation and interactive behaviour are inferred from the text and markup, not seen. Every page carries a "© 2026" footer. None shows a publication or last-updated date unless noted. Headings are quoted briefly. The fetcher summarised each page, so a few odd details are flagged as "unverified" where they look like extraction artefacts.

## 1. Which product, platform and feature URLs exist for each?

### Takeaway
All four run a very wide SEO surface: dozens of `/tool/`, `/make/` and `/features/` pages, plus role, industry and use-case pages. However, only Synthesia (`/video`, `/enterprise`) and HeyGen (`/agent`, `/ai-studio`) have clear "product" pages for the core product. InVideo and Pictory send the homepage, or one tool page, to do that job. None of the four has a dedicated public brand kit page. Pictory points its brand kit link at an Academy how-to article.

### Inferences
- The URL sprawl is SEO architecture: one page per input type (`X-to-video`), per model and per role. The real "product story" is concentrated on 2–3 pages per vendor. KeyFly does not need breadth to compete on the Product page. It needs one excellent narrative page.
- Synthesia's "Create / Translate / Manage / Publish / Engage" and Pictory's "Create / Edit / Scale" are the two most legible information architectures. Both group by workflow stage, not by technology.
- "Models" is now a top-level nav item for HeyGen and InVideo: they sell access to third-party models (Veo, Kling, Seedance, ElevenLabs).

### Gaps
- Dropdown contents for HeyGen's "Platform" menu and InVideo's "Product" menu were not exposed in the fetched text.
- Synthesia's /api, HeyGen's /translate and /enterprise, and Pictory's /pictory-enterprise and /pictory-api pages were not fetched individually (tool-call budget).

Synthesia groups by workflow stage (5 stages, about 24 features). HeyGen /agent shows 5 sections × 3 bullets. Pictory groups by input, then task, then role. InVideo's homepage has been rebuilt as an "agentic video editor" for footage, organised around capabilities.

## 3. How they explain prompt → script → scenes → voice → edit

### Takeaway
Everyone uses a 4-step "how it works" list. The stronger pages put a working prompt box in the hero: Synthesia's generator page, and HeyGen /agent with duration and orientation chips. Pictory is the most explicit about the pipeline: describe it, answer setup questions, review script and scenes, refine. Real before/after demonstrations are rare. No vendor shows a live, synchronised prompt → storyboard → timeline transformation.

### Cited Findings
- **HeyGen /agent** names the pipeline as four steps: "The script is written", "Images are selected", "Voiceover is added", "Edits and transitions". It has an interactive prompt box (0/500 characters) with duration chips (15s, 30s, 60s), orientation (Landscape, Portrait) and "Generate video". No sample prompts and no before/after; screenshots show the preview and editing UI — [HeyGen /agent](https://www.heygen.com/agent)
- **HeyGen /agent** sells control after generation: "Edit without re-rendering", "Click any element to modify", "Plain English feedback", "Pinpoint specific changes" — [HeyGen /agent](https://www.heygen.com/agent)
- **Synthesia /features/ai-video-generator** puts a live generator in the hero:
  - Inputs: a text prompt (500 characters), a script (1,500), a file (PPTX, PDF, DOCX or TXT; over 4,500 words is rejected) or a URL.
  - Advanced options: Speaker, Audience.
  - Sample prompts with thumbnails (onboarding, password security, a fictional product promo), and a rights-confirmation notice.
  - A 4-step section: start with text, customise, add AI B-roll, generate.

  [Synthesia AI video generator](https://www.synthesia.io/features/ai-video-generator)
- The **Synthesia** platform page only states that the AI Video Assistant turns a "prompt, script, or document" into video. It has no steps, demo or before/after — [Synthesia /video](https://www.synthesia.io/video)
- **Pictory homepage**, 4 steps:
  1. Describe the video (topic, audience, purpose, length, files or URLs).
  2. Answer setup questions (voiceover, visual sources, aspect ratio, layout, brand kit).
  3. Review the script and scenes.
  4. Refine by chat or in the editor, then generate.

  A linked workflow page describes 7 steps — [Pictory home](https://pictory.ai/)
- **Pictory /idea-to-video**, 4 steps with UI mockups: type the idea; pick type, platform and length; review and edit the script with "Ask AI"; choose a layout and download. It shows one sample prompt (a 60-second expense-policy explainer). A tabbed Script / Visuals / Voice-and-brand block explains each layer: hook, story and CTA script; "18M+" stock assets including Getty; 170+ voices — [Pictory idea to video](https://pictory.ai/idea-to-video)
- **Pictory /ai-video-editor** shows editing as a transcript mockup ("Search and replace", "Filler words Removed") and a sample chat that swaps a visual but keeps the narration. There is no side-by-side slider — [Pictory AI video editor](https://pictory.ai/ai-video-editor)
- The **Pictory homepage** has a photo-to-video before/after — [Pictory home](https://pictory.ai/)
- **InVideo /make/ai-video-generator/**:
  - A 4-step flow: prompt (pick workflow, fill details), generate (audience, platform, look; "Generate now"), edit with "Magic Box", publish.
  - Edit-command examples are limited to changing the accent or voice, deleting scenes and adding an intro.
  - Only a video poster image is shown; no demo or before/after.

  [InVideo AI video generator](https://invideo.io/make/ai-video-generator/)
- The **InVideo homepage** uses a four-node strip (Upload footage → Describe edit → Review cut → Export). Script, storyboard, voice and timeline appear as separate subsections, not as one sequence — [InVideo home](https://invideo.io/)
- **HeyGen's homepage** uses a research before/after: original vs generated footage for the Avatar V model — [HeyGen home](https://www.heygen.com/)

### Inferences
- The "4 steps" device is universal and interchangeable. A KeyFly page that *shows* the transformation, with one prompt visibly becoming a storyboard, voice-over, motion graphics and a timeline in sync, would out-explain all four. KeyFly's existing How it works and Creates sections already do this better than any page here.
- Pictory's "answer setup questions" and "review script and scenes before building" steps are a real differentiator in messaging: control before rendering. HeyGen makes the same point with "See Your Video Before It's Made". Control and preview are the shared anxiety these pages address.
- Edit-by-words examples are thin everywhere: three commands at InVideo, one chat swap at Pictory. A richer, concrete set of follow-up edits (like KeyFly's Edit with words) is an open gap.

### Gaps
- Whether the Synthesia and HeyGen hero generators actually produce video without sign-up could not be tested; the fetch only reads markup.
- Pictory's 7-step workflow page was not fetched.

## 8. Distinctive ideas worth beating, and what feels weak or generic

### Takeaway
Ideas worth beating:
- the live generator in the hero (Synthesia, HeyGen);
- "preview before render, edit after render" (HeyGen);
- control-first steps (Pictory's script review);
- workflow-stage IA (Synthesia);
- interactive templates (Synthesia);
- footage memory and batch edits (InVideo).

Weak spots:
- generic, repeated CTAs;
- 4-step lists with static screenshots;
- inconsistent and unsourced numbers;
- proof that is all logos and no watchable output;
- SEO filler ("What is X?").

### Cited Findings
- **Worth beating**:
  - The hero generator with prompt, script, file or URL inputs and sample prompts — [Synthesia AI video generator](https://www.synthesia.io/features/ai-video-generator)
  - The /agent prompt box with duration and orientation chips — [HeyGen /agent](https://www.heygen.com/agent)
  - Benefit-led section titles "See Your Video Before It's Made" and "Edit Everything After Rendering" — [HeyGen /agent](https://www.heygen.com/agent)
  - The four editing modes ("chat, text, scenes, AI Studio… combine them") — [Pictory AI video editor](https://pictory.ai/ai-video-editor)
  - Footage memory, "find by description" and "edit multiple shots in one go" — [InVideo home](https://invideo.io/)
  - Interactive templates (branching, quizzes, hotspots) — [Synthesia /features](https://www.synthesia.io/features)
  - The stakeholder-led enterprise line — [Synthesia /enterprise](https://www.synthesia.io/enterprise)
  - "Bring your own agents" (Claude Cowork, Codex, Grok, Gemini) — [InVideo home](https://invideo.io/)
- **Weak or generic**:
  - "Get Started For Free" ×7 on one page — [HeyGen /agent](https://www.heygen.com/agent)
  - Repeated identical card headings and a mismatched CTA label (fetch-reported, unverified) — [HeyGen /ai-studio](https://www.heygen.com/ai-studio)
  - "Eight panels" heading with six listed — [Pictory AI video editor](https://pictory.ai/ai-video-editor)
  - Conflicting user counts — [Synthesia AI video generator](https://www.synthesia.io/features/ai-video-generator), [HeyGen /alternatives](https://www.heygen.com/alternatives)
  - Unsourced 10X / $12K / 40% — [InVideo enterprise](https://invideo.io/enterprise/)
  - The FAQ answers "the best AI avatar generator in 2025" while the footer says © 2026 — [HeyGen /agent](https://www.heygen.com/agent)
  - Discount banners stacked above and inside the hero — [InVideo home](https://invideo.io/)
- **No vendor shows a synchronised visual of prompt → script → scenes → voice → timeline**. They use 4-step lists, screenshots or a single poster image — [InVideo AI video generator](https://invideo.io/make/ai-video-generator/), [HeyGen /agent](https://www.heygen.com/agent), [Pictory idea to video](https://pictory.ai/idea-to-video)

### Inferences
Ideas for a KeyFly Product page that would beat these, constrained by KeyFly's no-invention rules:
1. **One continuous, scroll-played transformation.** A single prompt becomes storyboard → voice-over → motion graphics → timeline → formats, with real app facts at each step. This replaces the generic 4-step list.
2. **Group by workflow stage, like Synthesia, but for an editor.** For example: Describe / Edit / Brand / Hand off. Each stage has one live demo, not a grid of cards.
3. **Show control, not just automation.** "Preview before, edit after, revert anytime" is the shared buyer anxiety. KeyFly's confirmed Revert, scene changes and "you keep the timeline" (FCPXML, EDL, OTIO export) answer it more concretely than HeyGen.
4. **Contextual CTAs** ("Try this prompt", "Open this in KeyFly") instead of one repeated button. Keep one quiet secondary contact path.
5. **Honest proof.** Watchable output plus a transparent capabilities list and confirmed data commitments, in place of logo walls KeyFly doesn't have. Avoid conflicting numbers by stating none until they are real.
6. **An "AI edit vs the manual way" table** (Pictory-style, qualitative) rather than named-competitor ✅/❌ tables.

### Gaps
- No user-research or conversion data was found on which of these page patterns convert best. The inferences above are design judgement, not evidence.
- Animation and interaction quality (how polished the hero demos feel in a browser) could not be assessed through text fetches.
