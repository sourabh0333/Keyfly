## Competitors (summary of a research pass; URLs in the session)

- **Main competitor:** one landing page per chat app (ChatGPT, Claude) with 3-step setup, recipe prompts with "Try in…", "No API key", clip limits, credits; Mac app connects to Claude Code and Codex. **No integrations hub, no NLE detail** (one FAQ line: Premiere, Final Cut, Resolve; no formats, no Avid, no package), no ACP, no Antigravity, nothing on what data leaves the machine.
- **Descript:** category bands with logos; the only NLE treatment found ("Timeline export" band). **Runway:** standalone MCP page with copyable prompts, credits note. **HeyGen:** four "paths" plus a tagged catalog (API / MCP / OAuth, "Coming soon"), FAQ on MCP cost. **Figma MCP catalog:** per-client capability labels (Remote/Local, Read/Write). **Linear:** "Agents" vs "AI clients" categories.
- **What works with few, deep integrations and no logos:** step-by-step setup, copyable real prompts, cost clarity, capability tables, honest limits and status badges, a FAQ, names as text.
